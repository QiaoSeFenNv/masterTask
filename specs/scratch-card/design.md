# 技术与视觉设计

场景：Operate。目标：选卡只了解角色概要，今日页通过触觉式擦除探索任务。美术方向：现有油画厚涂、金色文字的收藏卡；颜色沿用 theme 的 #070b16 / #e8dcc8 / #b3bdd4，不新增品牌色。标题使用项目 Canvas 的 Songti SC / STSong / Noto Serif CJK SC，正文沿用现有字体 token。375 宽画布、20 边距、单列今日内容，无新断点。

- 上方角色卡保留角色名与 tagline，使用已登记油画/渐变；下面的内容背卡为 335×340，提示与进度置于卡外。
- scratch.js：纯几何，圆头线段轨迹，34×34 网格估算擦除率；60% 自动完成。只记录实际新增覆盖的线段，最多网格数量，避免长手势内存增长。
- scratch-view.js：离屏 2D 覆盖层 + destination-out，擦除后贴到真实文字上；图片迟到时重新构造覆盖层并重放轨迹。离屏不可用/合成失败时以网格剪裁直接绘制未刮背景，保持完整回退。
- store：本机 roles.scratch.v1 存单条记录，按日期/角色/抽卡 seed 隔离；松手、切页、后台、完成时保存。读取、写入或数据损坏不影响玩法。任务/手记动作在刮开前额外防误触。
- render：未完成阶段只有 scratch 命中区，无任务/手记区；完整揭开后转现有任务列表，增加完整介绍区。所有今日内容剪裁到标题与导航之间。
- app：pointer/touch 起点决定刮卡或滚动，坐标锚定该手势开始时的卡；结束/取消清理手势。轮滚事件标注为滚动，不进入 scratch 分支。
- 候选详情不再画 intro，PAG 保持角色名/tagline 的简要揭晓。

验证：纯几何/保存恢复/无图回退/剪裁/手势隔离单测；真浏览器初始、半刮、刮完、刷新、取消、滚轮、320 宽与触摸截图；保留既有断言，在原流程中加入真实刮卡输入再继续任务断言。
