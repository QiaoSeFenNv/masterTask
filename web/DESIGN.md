# Web 体验预览设计规格

目的：通过可分享链接让其他人体验选包、撕包、选卡和 PAG 揭晓，并查看任务、日历与图鉴。每位访问者的体验数据只保存在自己的浏览器。

视觉方向：沿用现有小游戏的夜色背景、纸质卡包、角色卡面与金色文字。外层为简洁的操作界面，围绕实际游戏画面安排控件。

配色：外层背景 #071119，边框 #29424D，主要文字 #E9DBC1，次要文字 #AFC0C7，焦点 #A8E6CF。卡包与角色沿用现有资产和配色。

字体：外层标题使用 STSong / SimSun / serif；操作说明使用 Microsoft YaHei / sans-serif。Canvas 文字保留现有绘制方式。

布局：电脑上居中放置约 390 像素宽的竖屏体验区，高度随可用窗口调整；手机上游戏区占满可用宽度与高度。顶部提供名称与重新体验按钮，底部显示当前操作提示。输入弹层采用文字标签与可见确认、取消按钮。

交互：鼠标与触摸统一映射到 Canvas 内的坐标。选包增加约半秒的放大移动过渡；撕包跟随拖动，转盘继续跟手，揭晓复用同一 PAG 模板。切后台、窗口调整和再次体验保持可用。

验收：从首页使用真实点击和拖动完成一轮抽卡；看到选包过渡、撕口变化、三张翻面与 PAG 揭晓；任务勾选和手记可保存，刷新可恢复，日历和图鉴可访问；在手机尺寸上操作可用；分享链接加载资源成功，不依赖本地后端或微信登录。
